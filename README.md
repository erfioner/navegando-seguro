# Navegando Seguro

Support visuel en français avec quatre exemples courts, présentés un par écran. Après avoir répondu, le participant voit le résultat et les indices, puis peut passer au suivant. Le logo de la Fundación Ceili A.C. est affiché dans l’en-tête. Les réponses ne sont pas enregistrées.

## Utilisation

Ouvrez `index.html` pour afficher les exemples. Pour utiliser l’application sur iPad et l’installer sur l’écran d’accueil, publiez le dossier sur un hébergement HTTPS, ouvrez-le dans Safari, puis choisissez **Partager** et **Sur l’écran d’accueil**.

Pour remplacer la version précédente, copiez le contenu de ce dossier sur les anciens fichiers. Fermez puis rouvrez une installation PWA pour charger la nouvelle version.

`app.js` gère les réponses, `styles.css` l’affichage adaptatif, et `manifest.webmanifest` / `sw.js` les fonctions PWA. Les exemples sont pédagogiques ; le lien raccourci du SMS est affiché sans être cliquable.
